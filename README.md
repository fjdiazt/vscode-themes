# Vholf VS Code Themes

VS Code theme variants for Vholf BioSyn and EVA-01 palettes.

Included themes:

- `Vholf - BioSyn`
- `Vholf - BioSyn Soft`
- `Vholf - BioSyn Soft Inverted`
- `Vholf - eva-01`

The active development source is this repository. Install or symlink it as a VS Code extension during local testing, then run `Developer: Reload Window` in VS Code.

The BioSyn variants are inspired by retro sci-fi terminal palettes, including USCSS Nostromo and Alien terminal aesthetics. The `eva-01` theme is an Evangelion Unit-01-inspired palette built for this local theme set.
